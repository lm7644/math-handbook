8.1 全书符号总表

先看符号不约定会出多大的错。论文 A 里的 \(d\) 指 4096（整个模型的宽度），论文 B 里的 \(d\) 指 64（单个注意力头的宽度）——同一个字母差出 64 倍，照抄着估参数，结果直接错一个数量级。所以本章第一件事不是给表，而是先立「谁用什么字体」的规矩。

背景｜符号约定从哪来：向量、矩阵用粗体的记法，是二十世纪线性代数教材为区分「一列数」与「一个数」立下的排版传统；机器学习论文沿用至今，各家细节却互不统一。这张总表把全书用过的记号收进一处，替代「翻回原文找定义」的老办法——读论文撞见生符号，先来这里对号入座。

先立约定，再上表。全书约定：向量用粗体小写（\(\mathbf{x}\)，默认列向量），矩阵用粗体大写（\(\mathbf{W}\)），标量用斜体（\(x\)），集合用双线体（\(\mathbb{R}^{n}\)），损失用花体 \(\mathcal{L}\)，函数类算子用正体（\(\operatorname{softmax}\)）。下表按主题分组，「首见」指该符号第一次出现的章——忘了含义就按这一列回跳。

例 8.1 · 查表练习（给符号，查含义与首见章）

题目　读一篇 RLHF 博客，撞见这句话：「policy 用 Adam 更新，训练中监控 \(\operatorname{KL}(p\,\|\,q)\) 与 \(\mathrm{PPL}\)，\(\beta\) 系数取 0.04。」只用 §8.1 的符号总表，说出 \(\operatorname{KL}(p\,\|\,q)\)、\(\mathrm{PPL}\)、\(\mathbf{m}_t\) 各自的含义、首见章与相关式号，并指出句中 \(\beta\) 的隐患。

解　逐个对表。\(\operatorname{KL}(p\,\|\,q)\)：表中「含义」列为 KL 散度，式 (4.9)，用途注明「RLHF 的策略约束项」，首见第四章——与博客这句话的场景完全对上。\(\mathrm{PPL}\)：困惑度，「平均负对数似然的指数」，式 (4.10)，首见第四章。\(\mathbf{m}_t\)：句中没直接出现，但「用 Adam 更新」就有它——表中它是 Adam 的一阶动量状态，式 (5.8)(5.9)，首见第五章。\(\beta\) 的隐患：表下方「记号纪律」段写明，\(\beta\) 在第五章是 Adam 的衰减率，在第十一章是 KL 惩罚系数；这句博客恰好两个含义都可能沾上（既有 Adam 又有 KL），单凭这句话无法断定 0.04 指哪一个，必须回原文看上下文——这正是「先对符号表再读公式」的现实版。

例 8.2 · 动手算

题目　只用速查表，估算一个 7B 模型（\(L=32\)、\(d_{\text{model}}=4096\)）以 BF16 推理、上下文 4096 token、batch 为 1 时的显存占用。

解　显存分两块，一块一块算。第一块，权重。BF16 每参数 2 字节（第七章），

\[7\times10^{9}\ \text{参数}\times2\ \text{B}=1.4\times10^{10}\ \text{B}=14\ \text{GB}\approx13.0\ \text{GiB} \tag{8.2}\]

第二块，KV cache。注意力每步要用到全部历史 token 的 K、V（第十三章会细讲），每 token 每层存 K、V 各一份，共 \(2\cdot L\cdot d_{\text{model}}\) 个元素，乘 2 字节：

\[2\times32\times4096\times2=524288\ \text{B}=0.5\ \text{MiB/token}\ \Rightarrow\ 4096\ \text{token}\times0.5\ \text{MiB}=2\ \text{GiB} \tag{8.3}\]

合计约 \(13.0+2.0=15.0\,\text{GiB}\)，一张 24 GB 的显卡放得下。这就是速查表的典型用法：不推导，只代入（KV cache 的完整推导见第十三章式 (13.4) 与第十五章例 15.7）。python3 验算：\(2\cdot32\cdot4096\cdot2=524288\)，\(524288\times4096=2^{31}=2\,\text{GiB}\)，\(1.4\times10^{10}/2^{30}\approx13.04\)，全部吻合。

回头看 · 复盘这道例题

刚才干了什么：把显存拆成权重与 KV cache 两块 → 权重按「参数量 × 2 字节」代入 → KV cache 按「每 token \(2Ld_{\text{model}}\) 个元素」代入 → 相加后对照显卡容量。结论意味着：不推导、只代入，也能把 7B 模型的部署账算到 GB 级——第十三章式 (13.4) 会给出 KV cache 的完整推导，这里先练查表的手感。

例 8.3 · 动手算

题目　模型输出 logits \(\mathbf{z}=(2.0,\,1.0,\,0.1)\)。只用速查表里的温度采样公式，算 \(T=2\) 时的采样概率。

解　查表得温度采样公式 \(p_i^{(T)}=p_i^{\,1/T}/\sum_j p_j^{\,1/T}\)，它等价于把 logits 除以 \(T\) 再做 softmax（第三章式 (3.15)）。分三小步代入。第一步除温度：\(\mathbf{z}/T=(1.0,\ 0.5,\ 0.05)\)。第二步取指数：\(e^{1.0}\approx2.718\)、\(e^{0.5}\approx1.649\)、\(e^{0.05}\approx1.051\)，求和 \(Z\approx5.418\)。第三步归一化：

\[\mathbf{p}^{(T=2)}\approx\left(\dfrac{2.718}{5.418},\ \dfrac{1.649}{5.418},\ \dfrac{1.051}{5.418}\right)=(0.502,\ 0.304,\ 0.194) \tag{8.4}\]

对照 \(T=1\) 的 \((0.659,\ 0.242,\ 0.099)\)：温度拉高后分布明显变平——头部候选从 66% 跌到 50%，尾部从 10% 涨到 19%。python3 验算：np.exp([1.0,0.5,0.05]) 归一化得 (0.5017, 0.3043, 0.1940)，吻合。

常见坑

把速查表当知识本身。只背结论

\[\frac{\partial \mathcal{L}}{\partial z_i}=p_i-y_i\]

面试官追问一句「为什么」，就卡壳——答案在第二章的链式法则和第十五章例 15.3 的完整推导里。速查表是索引不是替身：每条公式都要能回跳到出处，把推导自己走一遍，才算真正拥有它。只背不推，等于把拳谱背熟了但从没上过擂台。

例 8.4 · 查表练习（给场景，查该用哪条公式）

题目　FP16 混合精度训练中，某一步梯度范数 \(\|\mathbf{g}\|=12\)，损失曲线出现毛刺尖峰。工程上开了损失缩放 \(S=256\)，梯度裁剪阈值 \(\tau=4\)。只用 §8.2 速查表回答：（1）毛刺尖峰与 FP16 下溢各该查表里哪一行？（2）更新前，梯度相对「缩放后的梯度」一共被乘了多少？

解　（1）按「用途 / 来源」列扫表：「吃掉梯度尖峰」对应梯度裁剪行（式 (2.18)、(7.6)）；「FP16 混合精度防梯度下溢」对应损失缩放行（式 (7.5)）。（2）按两行的公式依次代入。先还原：损失缩放行写明「更新前梯度除以 \(S\) 还原」，即乘 \(1/256\)。再裁剪：裁剪公式给出乘数 \(\min(1,\ \tau/\|\mathbf{g}\|)=\min(1,\ 4/12)=1/3\)，裁剪后范数 \(12\times1/3=4\)，恰好压到阈值 \(\tau\)——这正是该公式的目的。净效果：\((1/256)\times(1/3)=1/768\)。python3 验算：4/12 = 0.3333，12/3 = 4.0，256*3 = 768，吻合。

8.3 学习资源：读什么、读到哪

直觉 · 先建立感觉

这份清单的关键词是「配第几章」：先读本书对应章，再拿对应教材加深，顺序别反。每条都写死了「读到哪」，超出部分先放下，不用愧疚。论文按「先架构、后训练、再对齐与效率」的顺序读，每篇只抓 1–3 条核心公式，能复述每个符号就算读过。

背景｜这份书单从哪来：每条都是各自领域经受住时间检验的标准读物——Strang 的线代教材配 MIT 公开课影响了几代工程师，Goodfellow 等人的《Deep Learning》是深度学习第一本系统教科书。清单刻意保持短：每条注明「配第几章、读到哪」，是为了按需截取，而不是从第一页啃到最后一页。

第 1 题（符号识别）　不看 §8.1，说出下列符号的含义与首见章：\(d_k\)、\(d_{\text{model}}\)、\(h\)、\(L\)、\(\eta\)、\(T\)、\(\mathrm{PPL}\)、\(\beta_1\)。再回答：\(\sqrt{d_k}\) 出现在哪条公式里，作用是什么？

看答案

\(d_k\)：每个注意力头的键/查询维度，首见第零章式 (0.1)；\(d_{\text{model}}\)：隐藏维度（模型宽度），首见第六章；\(h\)：注意力头数，满足 \(d_k=d_{\text{model}}/h\)，首见第六章；\(L\)：Transformer 层数，首见第二章；\(\eta\)：学习率，首见第零章；\(T\)：采样温度，首见第零章；\(\mathrm{PPL}\)：困惑度（平均负对数似然的指数），首见第四章；\(\beta_1\)：Adam 一阶矩衰减率，首见第五章。\(\sqrt{d_k}\) 出现在缩放点积注意力 \(\operatorname{softmax}(\mathbf{Q}\mathbf{K}^{\top}/\sqrt{d_k})\mathbf{V}\)（式 (0.1)、(6.3)）里，作用是把点积打分的方差从 \(d_k\) 压回 \(O(1)\)，防止 softmax 饱和、梯度消失（推导见第十五章例 15.1）。答不出符号含义的，回对应首见章把定义框重读一遍。

第 2 题（速查表代入）　只用 §8.2 的速查表，估算一个 \(4096\times4096\) 的线性层（无偏置）有多少参数、以 BF16 存储占多少字节。再说出它在推理时属于「权重」还是「KV cache」开销。

看答案

参数量就是矩阵元素个数：\(4096\times4096=16777216\) 个，约 \(1.68\times10^{7}\)（1678 万）。BF16 每参数 2 字节：\(16777216\times2=33554432\ \text{B}=32\ \text{MiB}\)。它属于权重开销——固定成本，与 batch、上下文长度无关；KV cache 才是随业务量线性暴涨的可变成本（对照例 8.2 的两块分法）。python3 验算：4096*4096 = 16777216，16777216*2 = 33554432，\(33554432/2^{20}=32.0\)。
