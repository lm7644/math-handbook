强化学习与对齐的数学

PPO、DPO、GRPO 到底差在哪

预训练模型是个「博览群书但没家教」的孩子：什么都会接着说，就是不懂得好好回答问题。让它变「听话」靠的不是继续喂书，而是奖励与惩罚——这就是强化学习。本章不假设你学过任何 RL，从「训狗给零食」讲起，一步步推出策略梯度定理（含著名的对数导数技巧），再把工业界三个主流对齐算法 PPO、DPO、GRPO 逐个拆开：每个先讲直觉，再给公式，再用真数字算一遍。学完你能说清楚它们仨到底差在哪、什么时候用哪个。

11.1 强化学习的最小骨架：从训狗到语言模型

背景｜强化学习从哪来：上世纪中叶，行为心理学的「试错学习」与控制论的动态规划两路汇合；1990 年代策略梯度方法定型，2013 年后深度网络当策略（打砖块、AlphaGo）让它出圈。它替代的是「逐条手写规则」——规则写不尽的行为，交给奖励信号去筛。本章要解决的正是监督学习做不到的事：没有标准答案、只有好坏打分时，模型怎么学。
直觉 · 先建立感觉

强化学习就是训狗：狗做对动作，你立刻给一块零食；做错了，什么都不给（或者给个手势）。没有人一步步教它「先抬左腿再抬右腿」，它自己瞎试，试多了就发现「某些动作容易换来零食」，于是那些动作越做越多。强化学习只有三个要素：处境（狗看到主人举起手）、动作（狗坐下）、奖励（零食）。学习的全部目标就是：在各种处境下，多干容易换零食的事。跟监督学习的差别在哪？监督学习像老师逐题给标准答案，强化学习只告诉你「这次考得怎么样」，不告诉你「正确答案长什么样」——答案得自己试出来。

把训狗这套平移到大模型对齐上，每个词都有确切对应。模型看到 prompt（处境），一个词一个词地往外生成（动作），奖励模型给整段回答打个分（零食）：

RL 概念训狗版大模型对齐中的对应
状态 \(s_t\)主人举起手prompt 加上已生成的前 \(t-1\) 个 token
动作 \(a_t\)坐下 / 乱窜从词表中选下一个 token
策略 \(\pi_\theta\)狗的「习惯」语言模型本身：softmax 给出的词表概率分布
轨迹 \(\tau\)一整堂课的表现一段完整回答 \((s_1,a_1,\dots,s_T,a_T)\)
奖励 \(r\)零食奖励模型的打分，通常只在回答结束时给一次

先看一个只有两条出路的数字现场。某 prompt 下模型只会在两条回答里挑：回答 A 生成概率 0.6、奖励 1 分；回答 B 概率 0.4、奖励 0 分。期望总奖励就是 0.6×1 + 0.4×0 = 0.6。若训练把 A 的概率推到 0.8，期望升到 0.8×1 + 0.2×0 = 0.8——「让策略变好」落到数字上，就是把概率往高奖励的回答上搬。下面把这套说法写成正式定义。

定义 11.1

策略 \(\pi_\theta(a\mid s)\) 是在状态 \(s\) 下选动作 \(a\) 的概率分布，\(\theta\) 是模型的参数。一条轨迹的回报（return）是它收到奖励的总和 \(R(\tau)=\sum_{t=1}^{T}r_t\)。强化学习的优化目标是期望回报：

\[ J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\bigl[R(\tau)\bigr]=\mathbb{E}_{\tau\sim\pi_\theta}\Bigl[\sum_{t=1}^{T}r_t\Bigr] \tag{11.1} \]

读法：「让按当前策略玩下去的期望总奖励最大」。请盯一眼期望的下标 \(\tau\sim\pi_\theta\)：轨迹是从当前策略自己里采出来的。这意味着 \(\theta\) 既决定目标函数的值，又决定数据从哪来——模型表现变了，接下来看到的数据也跟着变。这是 RL 和监督学习最根本的差别，也是 RL 训练容易不稳的根源。

式 (11.1) 没法直接算：所有可能的回答加起来是天文数字，期望只能靠「采若干条回答、求平均」来近似（蒙特卡洛，第三章）。但真正的麻烦在下一步：我们要对 \(\theta\) 求梯度才能优化，而「从分布里采样」这个动作本身不可导——就像你能称出苹果的重量，却不能对「挑苹果」这个动作求导。梯度从哪来？这正是下一节要解决的、也是全章最核心的一个问题。

11.2 策略梯度定理：对数导数技巧与基线

直觉 · 先建立感觉

先想一个朴素方案：每生成一条回答，拿到奖励分；分高的回答，把里面每个词的出现概率调大一点；分低的，调小一点。「调大一点」的数学说法，就是对那些词的 log 概率求梯度、往增大方向走。这个朴素方案居然就是严格正确的——策略梯度定理证明，期望回报的梯度恰好等于「log 概率的梯度 × 奖励」的平均。妙处在于：梯度全部落在「已生成 token 的对数概率」上，采样动作本身被完全绕开了，根本不需要对它求导。让这件事成立的，是一个一行长的小技巧。

背景｜对数导数技巧从哪来：1960 年代仿真优化里就以「得分函数」之名出现，1992 年 Williams 拿它推出 REINFORCE，从此「采样」与「求导」分家——采样交给随机数，求导只碰 log 概率。这里需要它，是因为语言模型生成回答只能靠采样，而采样这个动作不可导，梯度必须另找出路。
推导 · 一步步来（对数导数技巧）

目标：从 \(J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]\) 推出一个「可以靠采样估计的梯度公式」。全程五步，每步交代理由。

第 1 步，把期望写成加权和。离散情形下，期望就是「每种结果 × 它的概率」加起来：\(J(\theta)=\sum_\tau \pi_\theta(\tau)\,R(\tau)\)。这里 \(\pi_\theta(\tau)\) 是整条轨迹的概率（等于各步概率连乘）。

第 2 步，直接求导，看看卡在哪。对 \(\theta\) 求导，求和号可以搬出去（导数是线性运算）：\(\nabla_\theta J=\sum_\tau \nabla_\theta\pi_\theta(\tau)\,R(\tau)\)。卡住了：右边是「梯度 × 数」的加权和，不再是「某个分布下的期望」，没法用采样近似——我们只会「按 \(\pi_\theta\) 采样求平均」，而这个式子外面没有 \(\pi_\theta\) 这个权重了。

第 3 步，对数导数技巧，把 \(\pi_\theta\) 变回来。对任何含参分布 \(p_\theta\)，由链式法则 \((\ln f)'=f'/f\)，两边乘 \(f\) 得 \(f'=f\cdot(\ln f)'\)。写成向量形式：

\[ \nabla_\theta\,p_\theta(x)=p_\theta(x)\,\nabla_\theta\log p_\theta(x),\qquad\text{即}\qquad \frac{\nabla_\theta p}{p}=\nabla_\theta\log p \tag{11.2} \]

为什么这一步合法？只是链式法则倒着用，没有引入任何近似。为什么这一步有用？它把「裸梯度」\(\nabla_\theta p\) 表示成「概率本身 × log 概率的梯度」，恰好把丢掉的权重 \(p_\theta(x)\) 还了回来。

第 4 步，代回去，期望复活。把式 (11.2) 用于 \(\pi_\theta(\tau)\)：\(\nabla_\theta J=\sum_\tau \pi_\theta(\tau)\,\nabla_\theta\log\pi_\theta(\tau)\,R(\tau)\)。现在每一项都有权重 \(\pi_\theta(\tau)\) 了，按期望的定义收回去：

\[ \nabla_\theta J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\bigl[\nabla_\theta\log\pi_\theta(\tau)\,R(\tau)\bigr] \tag{11.3} \]

这就是策略梯度定理的核心形状。意义：只要会采样轨迹、会对 log 概率求导（普通的反向传播就会），就能估计期望回报的梯度——「采样不可导」的障碍被绕过。

第 5 步，拆开轨迹的 log 概率。轨迹概率是各步连乘：\(\pi_\theta(\tau)=\prod_t \pi_\theta(a_t\mid s_t)\cdot(\text{环境转移概率})\)。取 log 变连加：\(\log\pi_\theta(\tau)=\sum_t\log\pi_\theta(a_t\mid s_t)+(\text{环境项})\)。环境转移（比如 prompt 是什么）不依赖 \(\theta\)，求导为 0，扔掉。代回式 (11.3) 得可用形式：

\[ \nabla_\theta J(\theta)=\mathbb{E}\Bigl[\sum_{t=1}^{T}\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,A_t\Bigr] \tag{11.4} \]

其中 \(A_t\) 是该动作的优势（advantage）：这个动作比平均水平好多少。最简版本 REINFORCE 直接拿整条轨迹的回报 \(R(\tau)\) 当 \(A_t\)：采 \(N\) 条回答求平均，\(\nabla J\approx\frac{1}{N}\sum_i\sum_t\nabla_\theta\log\pi_\theta(a_t^{(i)}\mid s_t^{(i)})\,R(\tau^{(i)})\)。

回头看 · 复盘这段推导

刚才五步干了什么：把期望展开成加权和 → 直接求导发现概率权重丢了 → 用链式法则把权重变回来（对数导数技巧）→ 收回期望形状 → 拆开轨迹、扔掉与参数无关的环境项。结论意味着：梯度只落在已采样 token 的 log 概率上，与监督训练共用同一条反向传播管线——后面 PPO、GRPO 的损失都从式 (11.4) 这个壳里长出来。

式 (11.4) 解释了为什么 LLM 能做 RL：前向照常一个 token 一个 token 采样（不用求导），反向只对词表分布的 log 概率下手——与监督训练共用同一条反向传播管线，工程上完全可行。

但 REINFORCE 有个实际毛病：方差大。回报的绝对数值波动剧烈（第三章例 3.1 已经见过：平均奖励 0.9、标准差 0.7），导致梯度估计忽大忽小、训练抖动。修法优雅得惊人：从优势里减去任何不依赖动作的常数 \(b\)（叫基线，baseline），期望纹丝不动：

\[ \mathbb{E}_{a\sim\pi_\theta}\bigl[\nabla_\theta\log\pi_\theta(a\mid s)\cdot b\bigr]=b\,\nabla_\theta\sum_a\pi_\theta(a\mid s)=b\,\nabla_\theta 1=0 \tag{11.5} \]

每一步的理由：\(b\) 不依赖动作，可以提到期望外面；期望里只剩 \(\nabla_\theta\log\pi\)，对它求期望等于 \(\nabla_\theta\sum_a\pi(a\mid s)\)（期望与求导换序）；概率加总是 1，常数的导数是 0。直觉：减去平均线，只看「比平均好多少」——好动作减完还是正，坏动作减完变成负，每个样本都给出方向一致的信号，方差实打实降下来，均值分毫不动。下面用真数字看一遍。

例 11.1 · 动手算（基线为什么降方差）

题目　单个状态、两个动作：\(a_1\) 是好回答（回报 \(R=1\)），\(a_2\) 是坏回答（\(R=0\)）。当前策略 logits 为 \(\mathbf{z}=(0,0)\)，即 softmax 后 \(\pi=(0.5,0.5)\)。比较「无基线」与「基线 \(b=0.5\)」时，单次采样得到的梯度估计（看 \(z_1\) 分量）的均值与方差。

解　先备料：softmax 求导（第二章），\(\partial\log\pi(a_1)/\partial z_1=1-\pi(a_1)=0.5\)，\(\partial\log\pi(a_2)/\partial z_1=-\pi(a_1)=-0.5\)。

第 1 步，无基线：采到 \(a_1\) 时估计 \(\hat g=R\times0.5=1\times0.5=0.5\)；采到 \(a_2\) 时 \(\hat g=0\times(-0.5)=0\)。两种采法各半概率，均值 \(=(0.5+0)/2=0.25\)，方差 \(=(0.5^2+0^2)/2-0.25^2=0.125-0.0625=0.0625\)。注意：一半的样本（采到坏回答）贡献的是零信号——「这次什么都没学到」。

第 2 步，加基线 \(b=0.5\)：采到 \(a_1\) 得 \((1-0.5)\times0.5=0.25\)；采到 \(a_2\) 得 \((0-0.5)\times(-0.5)=0.25\)。均值仍是 \((0.25+0.25)/2=0.25\)——式 (11.5) 保证无偏；但两个样本给出完全相同的估计，方差 \(=0\)。坏动作的梯度从「零信号」变成「明确压低 \(a_2\) 的 log 概率」。（以上数值均经 python3 验算。）

读数：基线不改平均方向，只把「这次采样的运气成分」挤掉。后面 PPO 用一个神经网络（价值网络）去学这个基线，GRPO 用同组样本的平均值现算——两者的分歧，根源就在这条式 (11.5)。

基线减的是「零期望的常数」：式 (11.5) 保证它不碰均值，省下的全是方差。记住这句，PPO 与 GRPO 的全部区别就是「基线从哪来」。

11.3 PPO：给更新拴根绳

直觉 · 先建立感觉

在线 RL 每轮的节奏是：用当前策略生成一批回答、打分、更新参数。风险在于：一步更新太猛，新策略跑得离旧策略太远，旧数据就全作废了——好比训狗时奖励标准一天三变，狗直接懵掉。PPO 的思路朴素又聪明：别让新策略一次跑偏太远，给更新拴根绳。具体拴法：盯着「新概率 ÷ 旧概率」这个比率，比率涨过 \(1+\varepsilon\) 或跌破 \(1-\varepsilon\)（\(\varepsilon\) 常取 0.1 或 0.2），就不再奖励继续前进——绳子到头了。这就是式 (11.7) 里 clip（裁剪）的全部含义。

先把「新概率 ÷ 旧概率」说严。在线 RL 用旧策略 \(\pi_{\mathrm{old}}\) 采样，却想改进新策略 \(\pi_\theta\)。连接两者的桥是重要性采样：对任意函数 \(f\)，

\[ \mathbb{E}_{a\sim\pi_\theta}[f(a)]=\mathbb{E}_{a\sim\pi_{\mathrm{old}}}\Bigl[\frac{\pi_\theta(a)}{\pi_{\mathrm{old}}(a)}\,f(a)\Bigr] \tag{11.6} \]

为什么成立？把右边期望按定义展开：\(\sum_a\pi_{\mathrm{old}}(a)\cdot\frac{\pi_\theta(a)}{\pi_{\mathrm{old}}(a)}f(a)\)，\(\pi_{\mathrm{old}}(a)\) 约掉，剩 \(\sum_a\pi_\theta(a)f(a)\)，正是左边。意思是：拿旧数据估计新策略的量，只要给每个样本乘一个「概率比」纠偏。定义逐 token 的概率比 \(r_t(\theta)=\pi_\theta(a_t\mid s_t)\,/\,\pi_{\mathrm{old}}(a_t\mid s_t)\)。朴素目标是最大化 \(\mathbb{E}[r_t(\theta)\hat A_t]\)：优势为正的动作，把它的概率比调大。问题：\(r_t\) 没有上界，一步激进更新就能把策略推飞，旧数据的代表性瞬间清零，训练崩掉。PPO（Schulman et al. 2017, arXiv:1707.06347）的修法是把比率裁进 \([1-\varepsilon,\,1+\varepsilon]\)，再取悲观的一支：

\[ \mathcal{L}^{\mathrm{CLIP}}(\theta)=\mathbb{E}_t\Bigl[\min\bigl(r_t(\theta)\hat{A}_t,\;\operatorname{clip}(r_t(\theta),\,1-\varepsilon,\,1+\varepsilon)\,\hat{A}_t\bigr)\Bigr] \tag{11.7} \]

读法：\(\min\) 永远从两个候选里挑更差的那个——\(\hat A_t>0\) 时给上涨封顶（概率涨够 \(\varepsilon\) 就不再多奖），\(\hat A_t<0\) 时不给下跌打折（压低够 \(\varepsilon\) 就停手）。比率一旦出界到「走过头」的那一侧（\(\hat A_t>0\) 时涨过 \(1+\varepsilon\)，或 \(\hat A_t<0\) 时跌破 \(1-\varepsilon\)），被选中的那支是不含 \(\theta\) 的常数，梯度为零——策略被「粘在」旧策略附近 \(\pm\varepsilon\) 的邻域里。这是信任区（trust region）思想的廉价实现：不相信大步更新，只在小圈子里稳步挪。下面把四种情形全算一遍，「悲观」就具体了。

1.1\(-1\)\(-1.10\)\(-1.10\)\(-1.10\)区间内，原样保留

再补两种出界情形体会「悲观」的对称性（python3 验算）：\(\hat A_t=+1\) 且 \(r_t=0.7\)（好动作概率跌太多）：\(\min(0.7,\,0.8)=0.7\)，选中未裁剪支——梯度继续把概率往回拉，不允许「跌穿绳子还不管」；\(\hat A_t=-1\) 且 \(r_t=0.7\)：\(\min(-0.7,\,-0.8)=-0.8\)，选中裁剪支——常数、梯度归零，压低概率压够 20% 就停手。六种行为合起来一句话：不管朝哪个方向，走满 \(\varepsilon\) 就失去动力。

完整的 PPO 还有一个部件：式 (11.7) 里的优势 \(\hat A_t\) 从哪来？答案是一个专门的价值网络（value network，又叫 critic）\(V_\phi(s)\)，它学着预测「这个状态平均能拿多少奖励」，优势 ≈ 实际奖励 − 价值预测。这正是例 11.1 那个基线的「可学习版」。于是 PPO 要同时训练策略和价值两个大网络，再加奖励模型、参考模型，一台戏四个模型——这是它贵且难调的根源，也是 §11.6 的 GRPO 要砍掉价值网络的动机。

clip 是一种悲观主义：两个候选目标里永远信更差的那个。乐观在这里没有好下场——离采样分布太远，旧数据说的就都不是真话了。

11.4 RLHF：三段式流水线与 KL 惩罚

直觉 · 先建立感觉

要把 PPO 用到语言模型上，还差一块：零食从哪来？总不能每生成一条回答都找真人打分——太慢太贵。工程上的解法是 RLHF（reinforcement learning from human feedback，人类反馈强化学习）：先请人少量打分、训一个「裁判模型」（奖励模型）模仿人的口味，再让裁判模型批量给模型的回答打分，用 PPO 去刷高这个分数。整个流程分三段，像办学校：先请名师示范（SFT），再培养裁判（奖励模型），最后让学生在裁判监督下苦练（PPO）。

第一段，SFT（监督微调）：收集人工写好的「指令 + 示范回答」，做普通的极大似然训练（第三、四章），得到模型 \(\pi_{\mathrm{ref}}\)。作用：先让模型学会「回答问题」这个行为模式本身，也充当后面第三段的锚点。

背景｜Bradley–Terry 模型从哪来：1952 年为象棋选手评级而生——手里只有「谁赢谁」的对局记录、没有绝对分数，它用「分数差过 sigmoid」把成对胜负反推成每个选手的隐藏分，替代了粗暴的胜率计数。这里处境一模一样：标注员只说哪条回答好，奖励模型就是那个被反推出来的隐藏分。

第二段，训奖励模型：同一个 prompt 让模型生成两条回答，人工标注哪条好，记 \(y_w\succ y_l\)（w 是 winner，l 是 loser）。怎么把「这条更好」变成可训练的分数？用 Bradley–Terry 偏好模型：

先拿真数字感觉一下「分差变概率」。裁判给好回答打 2.0 分、坏回答打 0.5 分，分差 1.5，sigmoid(1.5) ≈ 0.82——即裁判以 82% 的把握说好的那条更好；两条同分时 sigmoid(0) = 0.5，等于抛硬币；分差拉到 4，把握升到约 0.982。下面这个定义就是把「分差过 sigmoid」写成正式模型。

定义 11.2

给定奖励函数 \(r_\phi(x,y)\)（\(\phi\) 是奖励模型的参数），回答 \(y_w\) 优于 \(y_l\) 的概率建模为

\[ P(y_w\succ y_l\mid x)=\sigma\bigl(r_\phi(x,y_w)-r_\phi(x,y_l)\bigr) \tag{11.8} \]

\(\sigma\) 是 sigmoid。读法：奖励差越大，判 \(y_w\) 胜出的概率越接近 1；奖励相等时恰为 0.5（抛硬币）。注意偏好只由奖励差决定——给所有奖励整体加一个常数，比较结果不变。训练奖励模型就是把式 (11.8) 当二分类做的交叉熵：\(\mathcal{L}_{\mathrm{RM}}=-\mathbb{E}\bigl[\log\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))\bigr]\)，即让真人认可的排序尽量大概率地复现。

第三段，PPO：以 \(\pi_{\mathrm{ref}}\) 初始化策略 \(\pi_\theta\)，最大化

\[ \max_\theta\ \mathbb{E}_{y\sim\pi_\theta(\cdot\mid x)}\bigl[r_\phi(x,y)\bigr]-\beta\,\operatorname{KL}\!\left(\pi_\theta\,\middle\|\,\pi_{\mathrm{ref}}\right) \tag{11.9} \]

第一项就是刷奖励模型的分。第二项是新面孔：策略与参考模型之间的 KL 散度（第四章），乘系数 \(\beta\) 后从目标里减去——新策略离参考模型越远，惩罚越重。为什么它必须存在？因为奖励模型只是真人偏好的代理，只在人类标注过的数据分布附近可信；策略一旦跑远，刷高奖励不再需要回答真的好，只需要钻裁判的空子——这叫 reward hacking（奖励黑客），典型症状是奖励分猛涨、输出却退化成重复套话。KL 项就是把策略拴在 \(\pi_{\mathrm{ref}}\) 附近的绳：既是防跑偏的绳，也是保住语言能力的锚（锚太远，模型会为了奖励牺牲流畅性）。\(\beta\) 控制松紧：越大越保守、越不敢偏离 SFT 模型。

奖励模型是代理不是真相。KL 项拴的就是「别走出代理可信的半径」——半径之外，高分低能是必然事件。

11.5 DPO：不训裁判，直接拿偏好对调教

直觉 · 先建立感觉

RLHF 的痛点在工程：奖励模型、PPO、价值网络、参考模型，四个大模型两台戏，采样、打分、更新环环相扣，任何一环没调好全盘皆输。DPO（直接偏好优化，direct preference optimization；Rafailov et al. 2023, arXiv:2305.18290）的姿态是：不训奖励模型、不在线采样，直接拿标注好的偏好对 \((y_w,y_l)\) 当监督数据调教模型——既然我们最终要的只是「好回答概率变大、坏回答概率变小」，为什么不直接优化这件事，非要绕道训个裁判再打 RL？听起来像抄近路，但它有严格的数学依据：式 (11.9) 的最优解可以解析地写出来，奖励能在推导中被「消元」掉。下面把这个推导走完，每一步都有交代。

推导 · 一步步来（从 RLHF 目标到 DPO 损失）

第 1 步，写出 RLHF 目标的最优策略。固定参考模型 \(\pi_{\mathrm{ref}}\) 和奖励 \(r\)，对式 (11.9) 关于分布 \(\pi\) 求最优（要满足「概率加和为 1」的约束，用变分法；这一步只取结论，细节超出本手册范围），最优策略是参考模型的「指数倾斜」：

\[ \pi^{*}(y\mid x)=\frac{1}{Z(x)}\,\pi_{\mathrm{ref}}(y\mid x)\exp\!\left(\frac{r(x,y)}{\beta}\right) \tag{11.10} \]

其中 \(Z(x)=\sum_y\pi_{\mathrm{ref}}(y\mid x)\exp(r(x,y)/\beta)\) 是配分函数（归一化常数，保证概率加和为 1），只依赖 \(x\)。直觉：最优策略 = 在参考模型基础上，按奖励的指数重新加权——奖励高的回答被成比例地抬高，\(\beta\) 控制抬得多狠（\(\beta\) 小 → 抬得狠 → 离参考远）。

第 2 步，反解出奖励。对式 (11.10) 两边取 log、整理（\(\log\) 把除法变减法、把 exp 消掉）：

\[ r(x,y)=\beta\log\frac{\pi^{*}(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)}+\beta\log Z(x) \tag{11.11} \]

意思：奖励可以表示成「最优策略相对参考模型的对数比」，外加一个只依赖 \(x\) 的项。

第 3 步，代入偏好模型，消掉 \(Z(x)\)。把式 (11.11) 代入 Bradley–Terry 式 (11.8)：两条回答的奖励相减时，\(\beta\log Z(x)\) 对两条回答完全相同，相减恰好消掉！剩下

\[ P(y_w\succ y_l\mid x)=\sigma\!\left(\beta\log\frac{\pi^{*}(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}-\beta\log\frac{\pi^{*}(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\right) \]

注意右端已经没有奖励 \(r\) 了——奖励模型在推导中被消元，从头到尾不需要实例化。

第 4 步，把 \(\pi^{*}\) 换成待训的 \(\pi_\theta\)，最大化人类偏好数据的似然，即得 DPO 损失：

\[ \mathcal{L}_{\mathrm{DPO}}=-\mathbb{E}_{(x,y_w,y_l)}\log\sigma\!\left(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\right) \tag{11.12} \]

读法：这是监督式交叉熵的形状——让「好回答相对参考模型的对数比」尽量大于「坏回答的对数比」。偏好对是事先收集好的固定数据，没有采样、没有概率比、没有价值网络，用普通的 Adam（第五章）就能训。式 (11.12) 里的 \(\beta\) 还是式 (11.9) 里那个 KL 系数：由式 (11.10)，同样的奖励差距下 \(\beta\) 越小策略偏离参考越远，即 \(\beta\) 越大越保守。

回头看 · 复盘这段推导

刚才四步干了什么：写出 RLHF 目标的最优策略（按奖励指数倾斜参考模型）→ 反解出奖励 → 代入 Bradley–Terry 偏好模型，配分函数相减消掉 → 换成待训策略写成普通交叉熵。结论意味着：奖励模型在推导中被消元，偏好对直接当监督数据用——不采样、不训裁判，这就是 DPO 便宜又稳定的根源。

例 11.3 · 动手算（DPO 损失一项）

题目　取 \(\beta=0.1\)。对某个 prompt，当前模型与参考模型给两条回答的概率为：\(\pi_\theta(y_w\mid x)=0.25\)、\(\pi_{\mathrm{ref}}(y_w\mid x)=0.20\)；\(\pi_\theta(y_l\mid x)=0.10\)、\(\pi_{\mathrm{ref}}(y_l\mid x)=0.20\)。算这一项的 DPO 损失。

解　第 1 步，算两个对数比：好回答 \(\ln(0.25/0.20)=\ln1.25\approx0.2231\)；坏回答 \(\ln(0.10/0.20)=\ln0.5\approx-0.6931\)。第 2 步，代入式 (11.12) 括号：\(0.1\times(0.2231-(-0.6931))=0.1\times0.9163\approx0.0916\)。第 3 步，过 sigmoid、取负对数：\(\sigma(0.0916)\approx0.5229\)，损失 \(-\ln0.5229\approx0.6484\)（python3 验算）。

读数：当前模型把好回答相对参考模型抬高了（对数比 +0.22）、把坏回答压低了（−0.69），方向已经对，但差距换算成的胜出概率只有 52%，勉强过半，损失离 0 尚远。梯度的方向正是继续拉大两个对数比——好回答变得比参考模型更常见，坏回答更少见。

DPO 里没有显式的 KL 项，但 \(\beta\) 与「对数比」共同把 KL 约束藏进了损失：策略离参考太远时对数比变大、sigmoid 饱和、梯度变小——正则化是隐式的，不是没有。

11.6 GRPO：同题采一组，组内互相比

直觉 · 先建立感觉

PPO 最贵的一个零件是价值网络——为了知道「比平均好多少」，专门训一个网络估「平均是多少」。GRPO 的想法是：同一道题，让模型一口气答 G 遍，组内互相比，不用单独训裁判来估平均线。好比评估一个学生：不问他「比全校平均分高多少」（得先统计全校），而是让他同一份卷子做 8 次，8 个分数一摆，哪次好哪次差一目了然，平均线当场算出来。组均值就是基线——式 (11.5) 保证它不进期望，零参数、零训练误差。这就是 GRPO（组相对策略优化，group relative policy optimization；Shao et al. 2024, arXiv:2402.03300；后来用于 DeepSeek-R1 的推理训练）的全部核心。

形式化：对同一 prompt \(x\)，用旧策略一次采 \(G\) 条回答，拿到组内奖励 \(r_1,\dots,r_G\)，优势直接用组内统计标准化：

\[ \hat{A}_i=\frac{r_i-\operatorname{mean}(\mathbf{r})}{\operatorname{std}(\mathbf{r})},\qquad \operatorname{mean}(\mathbf{r})=\frac{1}{G}\sum_{j=1}^{G}r_j,\qquad \operatorname{std}(\mathbf{r})=\sqrt{\frac{1}{G}\sum_{j=1}^{G}\bigl(r_j-\operatorname{mean}(\mathbf{r})\bigr)^{2}} \tag{11.13} \]

（口径注记：式 (11.13) 的标准差按 DeepSeek 原文用 \(1/G\) 归一；部分工程实现改用无偏的 \(1/(G-1)\)，\(G\) 较大时差异可忽略，对接代码时先对齐口径。）

目标函数沿用 PPO 的 \(\min\)-\(\operatorname{clip}\) 形状（式 (11.7) 的骨架），另加 KL 项：

\[ \mathcal{L}_{\mathrm{GRPO}}(\theta)=\mathbb{E}\Bigl[\frac{1}{G}\sum_{i=1}^{G}\frac{1}{|y_i|}\sum_{t=1}^{|y_i|}\min\bigl(\rho_{i,t}\hat{A}_i,\;\operatorname{clip}(\rho_{i,t},\,1-\varepsilon,\,1+\varepsilon)\hat{A}_i\bigr)\Bigr]-\beta\,\operatorname{KL}\!\left(\pi_\theta\,\middle\|\,\pi_{\mathrm{ref}}\right) \tag{11.14} \]

其中 \(\rho_{i,t}=\pi_\theta(y_{i,t}\mid x,y_{i,<t})\,/\,\pi_{\mathrm{old}}(y_{i,t}\mid x,y_{i,<t})\) 是第 \(i\) 条回答第 \(t\) 个 token 的概率比（式 (11.6) 的逐 token 版）。

与 PPO 的差别就两条，都值得说透。其一，基线从哪来：式 (11.13) 的组均值正是 §11.2 的基线 \(b\)——PPO 用一个网络去学它，GRPO 用同组 \(G\) 条样本现算，省掉一整个网络的训练开销和不稳定。其二，除以标准差是难度归一：全对的简单题（奖励全 1）与全错的难题（奖励全 0），组内方差都接近零，优势信号自动消失——梯度自动集中在「有区分度」的中等难度题上，这恰好是学习效率最高的地方。代价是每个 prompt 要采 \(G\) 条回答：用推理开销换掉了价值网络。

例 11.4 · 动手算（组内优势）

题目　某 prompt 采 \(G=4\) 条回答，奖励为 \((0.9,\,0.4,\,0.7,\,0.2)\)。按式 (11.13) 求各条的组内优势。

解　第 1 步，组均值：\((0.9+0.4+0.7+0.2)/4=2.2/4=0.55\)。第 2 步，组标准差：各条离均值的差为 \((0.35,\,-0.15,\,0.15,\,-0.35)\)，平方和 \(=0.1225+0.0225+0.0225+0.1225=0.29\)，除以 \(4\) 得 \(0.0725\)，开方 \(\approx0.2693\)。第 3 步，逐条代入式 (11.13)：\(\hat A\approx(1.30,\,-0.56,\,0.56,\,-1.30)\)（python3 验算）。

读数：四项之和恰为 0——「减去均值」的零均值性质在样本层面精确成立；最好与最差的回答得到幅度相同、方向相反的信号，全程没有任何额外网络参与。再体会难度归一：若四条全对 \((1,1,1,1)\)，标准差为 0、优势无意义——组内必须有好有坏，GRPO 才有燃料。

11.7 三者对照与常见坑

直觉 · 先建立感觉

这是类比：三者像三种请家教的方案——PPO 是全职团队，裁判、估分师都请，最贵也最灵活；DPO 只刷整理好的错题本，便宜省事，但学不到本上没有的题；GRPO 让同一份卷子连做 \(G\) 遍互相对分，省掉估分师，代价是做题量翻倍。这个类比省掉了什么：只说工程取舍，没说三者共用同一条数学主干（式 (11.4)(11.5)），也没覆盖各自的稳定机制。

例 11.5 · 动手算（同一批数据，PPO 与 GRPO 的优势差多少）

题目　某 prompt 下旧策略采了 \(G=2\) 条回答，奖励 \((1,\,0)\)。（a）若 PPO 的价值网络预测 \(V(s)=0.3\)，两条回答的优势各是多少？（b）按式 (11.13)，GRPO 的组内优势各是多少？（c）设 \(\varepsilon=0.2\)，好回答上某 token 的概率比 \(r_t=1.3\)，用两种优势分别算式 (11.7) 这一项的值，并说明梯度状态。

解　第 1 步，PPO 的优势：优势 = 实际奖励 − 价值预测，好回答 \(1-0.3=0.7\)，坏回答 \(0-0.3=-0.3\)。第 2 步，GRPO 的优势：组均值 \((1+0)/2=0.5\)；离差 \((0.5,\,-0.5)\)，平方和 \(0.25+0.25=0.5\)，除以 \(2\) 得 \(0.25\)，开方得组标准差 \(0.5\)；标准化后优势为 \((+1,\,-1)\)。第 3 步，过好回答的 clip（裁剪区间 \([0.8,\,1.2]\)，\(r_t=1.3\) 越界上沿）：用 PPO 优势 \(0.7\)，未裁剪支 \(1.3\times0.7=0.91\)，裁剪支 \(1.2\times0.7=0.84\)，\(\min(0.91,\,0.84)=0.84\)；用 GRPO 优势 \(1\)，未裁剪支 \(1.3\times1=1.3\)，裁剪支 \(1.2\times1=1.2\)，\(\min(1.3,\,1.2)=1.2\)（以上均经 python3 验算）。两种情况下被选中的都是裁剪支，\(1.2\) 是常数边界、不含 \(\theta\)，所以这一 token 的梯度都为 0——涨幅已用满绳长。

读数：同一批数据、同一根绳、同一个封顶结局，只因基线来源不同，目标值就差了一截（0.84 对 1.2）。PPO 的优势里混着价值网络的估计误差（\(V(s)=0.3\) 是学出来的，可能估错），GRPO 的优势只由这组数据决定、零参数。对照表里「价值网络：需要 / 不需要」那一行，落到数字上就是这个差别。

回头看 · 复盘这道例题

刚才三步干了什么：同一批数据分别用「价值网络估的基线」（PPO）和「组均值现算的基线」（GRPO）算优势 → 过好回答的 clip 绳 → 两种算法都封顶、这一 token 梯度都为零，但目标值 0.84 对 1.2 差了一截。结论意味着：PPO 与 GRPO 的分歧不在绳、而在基线的来源——选基线来源，就是选工程预算的打法。

常见坑

把 DPO 当在线算法。式 (11.12) 的推导前提是偏好对 \((y_w,y_l)\) 来自固定的人类标注分布。拿当前 \(\pi_\theta\) 自生成的回答冒充新标注、边训边标，就破坏了离线监督的前提，退化成模型自己给自己打分的循环。要用在线数据得换在线变体，不能直接套式 (11.12)。

常见坑

把 KL 系数 \(\beta\) 设成 0。式 (11.9) 退化为纯奖励最大化：策略几轮之内就能找到奖励模型的漏洞，奖励分猛涨而输出退化成重复、套话甚至乱码，且因离 \(\pi_{\mathrm{ref}}\) 太远很难训回。\(\beta\) 必须为正；训练中要盯 KL 数值曲线，而不是只看奖励曲线——奖励涨、KL 也暴涨，就是 reward hacking 在进行。

常见坑

GRPO 组大小取 \(G=1\)。式 (11.13) 中 \(r_1-\operatorname{mean}(\mathbf r)=0\)，标准差也无定义，优势恒为 0，梯度整场为零——训练空转且不报错。同理，组内 \(G\) 条全对或全错（奖励全同）时优势也全为 0：GRPO 的燃料是「有区分度」的 prompt，数据难度分布本身就是超参数。

11.8 在 AI 中的位置

本章结论用在哪个具体组件 / 机制缺了会怎样
策略梯度与对数导数技巧，式 (11.3)(11.4)RLHF / 推理训练的梯度来源：只对已采样 token 的 log 概率求导以为要对「采样」本身求导，训练管线根本搭不起来
基线的零期望性质，式 (11.5)REINFORCE 减方差、PPO 价值网络、GRPO 组均值的共同理论依据梯度估计方差爆炸，训练抖动不收敛还找不到病因
PPO 裁剪目标，式 (11.7)在线对齐训练的信任区；InstructGPT（Ouyang 2022）的第三段不裁剪则一步激进更新推飞策略，旧数据失效、训练崩掉
Bradley–Terry 模型，式 (11.8)奖励模型训练：把成对偏好变成标量奖励偏好标注无法变成可优化的目标，RLHF 第二段无从谈起
KL 惩罚项，式 (11.9)防 reward hacking、保住语言能力\(\beta=0\) 时策略钻奖励模型空子，分数涨、输出崩
DPO 闭式解与损失，式 (11.10)(11.12)离线对齐：跳过奖励模型与在线采样，偏好数据直接监督式训练把 DPO 当在线算法用，前提全错，训练成自评循环
组内标准化优势，式 (11.13)GRPO：DeepSeek-R1 式推理训练（Shao 2024），无价值网络\(G=1\) 或组内同分时零梯度空转；不懂难度归一则误配数据

对齐工程的取舍一句话收束：PPO、DPO、GRPO 的分歧全在工程，不在数学主干——主干只有一条：用对数导数技巧把「采样」变成「对 log 概率求导」（式 (11.4)），再用基线压方差（式 (11.5)）。基线用网络学（PPO）、干脆不走 RL（DPO）、还是用同组样本现算（GRPO），取决于你有多少预算、有没有可自动判分的奖励（数学、代码题有标准答案，GRPO 的天然主场）、以及能不能容忍在线采样的复杂度。

自测题

题 1（基线与 REINFORCE）　单状态两动作：\(\pi(a_1)=0.6\)、\(\pi(a_2)=0.4\)，回报 \(R(a_1)=1\)、\(R(a_2)=0\)，取基线 \(b=0.4\)。求两种采样结果各自对 \(z_1\) 的梯度估计，以及估计的期望。

看答案

softmax 求导：\(\partial\log\pi(a_1)/\partial z_1=1-0.6=0.4\)；\(\partial\log\pi(a_2)/\partial z_1=-0.6\)。采到 \(a_1\)：\((1-0.4)\times0.4=0.24\)；采到 \(a_2\)：\((0-0.4)\times(-0.6)=0.24\)。期望 \(=0.6\times0.24+0.4\times0.24=0.24\)（python3 验算）。两种采样给出同一估计，方差为 0——\(b=0.4\) 正是让两种估计相等的取值：\((1-b)\times0.4=b\times0.6\) 的解，即本题的方差最优基线。注意它并不等于平均回报 \(\mathbb{E}[R]=0.6\)：最优基线按各动作梯度幅度加权（加权平均给出 \(b^{*}=0.4\)），「减去平均线」只是近似直觉，严格说减的是「梯度加权的平均线」。

题 2（PPO 裁剪）　\(\varepsilon=0.1\)，某 token 的比率 \(r_t=1.25\)，优势 \(\hat A_t=+2\)。式 (11.7) 的值是多少？这项的梯度是多少？为什么？

看答案

未裁剪支 \(=1.25\times2=2.5\)；裁剪支 \(=\operatorname{clip}(1.25,0.9,1.1)\times2=1.1\times2=2.2\)；\(\min(2.5,2.2)=2.2\)（python3 验算）。被选中的是裁剪支 \(1.1\times2\)，其中不含 \(\theta\)（1.1 是常数边界），所以这项对 \(\theta\) 的梯度为 0。含义：好动作的概率已经涨超 \(+10\%\) 的绳长，PPO 拒绝为超出部分继续给奖励——封顶保稳定。

题 3（DPO 损失）　\(\beta=0.5\)。某 prompt 下：\(\pi_\theta(y_w\mid x)=0.30\)、\(\pi_{\mathrm{ref}}(y_w\mid x)=0.20\)；\(\pi_\theta(y_l\mid x)=0.10\)、\(\pi_{\mathrm{ref}}(y_l\mid x)=0.25\)。算这一项的 DPO 损失，并说明当前模型做得好不好。

看答案

对数比：\(\ln(0.3/0.2)=\ln1.5\approx0.4055\)；\(\ln(0.1/0.25)=\ln0.4\approx-0.9163\)。括号：\(0.5\times(0.4055+0.9163)=0.5\times1.3218\approx0.6609\)。\(\sigma(0.6609)\approx0.6595\)，损失 \(-\ln0.6595\approx0.4163\)（python3 验算）。模型当前认为好回答胜出的概率约 66%——方向正确但信心不足；继续训练就是继续拉大两个对数比。

题 4（GRPO 优势与 \(G=1\)）　某 prompt 采 \(G=3\) 条回答，奖励 \((2,1,0)\)。求组内优势；再解释为什么 \(G=1\) 时训练必然空转。

看答案

均值 \(=(2+1+0)/3=1\)；离差 \((1,0,-1)\)，平方和 \(=2\)，除以 3 得 \(2/3\approx0.6667\)，标准差 \(\approx0.8165\)；优势 \(=(1.2247,\,0,\,-1.2247)\)（python3 验算）。\(G=1\) 时：均值就是唯一样本自己，分子 \(r_1-\operatorname{mean}=0\)，且标准差无定义，优势恒为 0——式 (11.14) 中每一项都乘 0，梯度整场为零，参数一步不动，还不报错。GRPO 至少要 \(G\ge2\)，且组内奖励要有差异。
